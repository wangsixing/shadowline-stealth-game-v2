SHADOWLINE — a top-down 2D canvas stealth game: one night at the Meridian Gallery. Slip past patrolling guards and their vision cones, steal the artifact, and reach the exit. Two levels (Gallery, Vault), raycast sight, a detection meter, cover and shadow, sprint noise, and synthesized WebAudio. No build step, no dependencies.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser. Controls: WASD to move, Shift to sprint, C to crouch, R to restart, M to mute, Enter to start.
